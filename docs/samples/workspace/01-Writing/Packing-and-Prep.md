# Packing and prep

## Thursday

- [x] Read the route notes
- [x] Check the return train
- [ ] Share the meeting point
- [ ] Pack the first aid kit
  - [x] Add spare blister plasters
  - [ ] Replace the expired cold pack
- [ ] Print a map for the group

## Saturday morning

1. Meet at the station.
2. Choose the route together.
   1. Check the wind and visibility.
   2. Count the group before leaving.
3. Send the route and expected return time to the desk.

## Pack by category

- Water
  - Two bottles
  - A spare bottle for the group
- Layers
  - Rain shell
  - Gloves
- Navigation
  - Paper map
  - Offline route on phone
