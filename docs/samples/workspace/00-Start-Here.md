## Try the file pane

1. Open [Bridge Follow-up](04-Field-Notes/Archive/Bridge-Follow-Up.md) from the file tree and bookmark it.
2. With that note active, click **New**. The new note should appear next to it in **Archive**.
3. Drag the new note onto **04-Field-Notes**, then reopen it from its new location.
4. Right-click [Trail Memo](01-Writing/Trail-Memo.md) in the file tree and choose **Open in New Tab**.
5. Search the workspace for `ridge` to find it in several notes.

If you want a clean starting point for future experiments, copy the workspace folder before editing it.
