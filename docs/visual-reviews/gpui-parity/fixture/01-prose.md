# Quiet review

CalmMD should feel like a finished page while the source stays one keystroke away. The interface is
deliberately quiet: **paper**, **ink** and a single amber accent.

> [!note] Working rule
> The page is the product. Controls recede until they are needed.

A short paragraph after the callout keeps the reading rhythm calm and gives both previews the same
line-height and measure to compare.
